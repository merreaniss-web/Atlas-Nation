# ATLAS NATIONS — version 1.0

Jeu de stratégie et de gestion nationale pour navigateur, ordinateur, tablette et téléphone.

## Installation sur GitHub Pages
1. Créez un dépôt GitHub public `atlas-nations`.
2. Ajoutez les quatre fichiers de ce dossier à la racine : `index.html`, `styles.css`, `app.js`, `README.md`.
3. Dans **Settings → Pages**, choisissez **Deploy from a branch**, branche `main`, dossier `/ (root)`, puis **Save**.
4. Ouvrez l'URL publiée par GitHub Pages.

Aucune compilation ni installation de dépendances n'est nécessaire. Une connexion Internet est nécessaire pour charger Leaflet, les frontières GeoJSON et la police web. En cas de coupure réseau, les menus de simulation restent disponibles, mais la carte ne peut pas charger ses frontières.

## Fonctionnalités de la version
- Interface responsive et thème stratégie premium.
- Sélection parmi plus de 40 nations, drapeaux emoji et profils de départ différenciés.
- Carte du monde interactive et sélection de nations.
- Horloge de jeu, pause et vitesses ×1, ×3, ×10.
- Économie : PIB, croissance, budget, fiscalité, dette, chômage, inflation et commerce.
- Société : bonheur, population stylisée, chômage et six régions de jeu.
- Politique : popularité, stabilité, conseil de gouvernement et élections simulées.
- Diplomatie : relations bilatérales, accords commerciaux et pactes de sécurité.
- Défense : allocation de budget, sécurité et coopération.
- Recherche : effort national et programmes énergie, santé et industrie.
- Événements aléatoires, actualités, objectifs et graphique économique.
- Sauvegarde locale, export JSON et import JSON.

## Notes
Les statistiques sont des variables de jeu stylisées, et non des données officielles actualisées. Les frontières proviennent d'un GeoJSON public et les tuiles cartographiques ne sont pas nécessaires à l'affichage. Les relations internationales et les élections sont modélisées pour le gameplay; ce n'est pas un outil de prévision politique, économique ou militaire.
