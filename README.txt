ATLAS NATIONS V2

Installation:
1. Decompressez le ZIP.
2. Remplacez le index.html à la racine de votre dépôt GitHub.
3. Commit changes, attendez GitHub Pages puis rechargez en vidant le cache (Ctrl+F5 sur PC).

Application autonome : aucun fichier externe requis pour afficher l'interface.
Les données de gameplay sont simulées; partis et institutions servent de références de départ et ne sont pas des données politiques en temps réel.
Sauvegarde locale, export et import JSON inclus.
